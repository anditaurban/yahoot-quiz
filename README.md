# Yahoot! — Frontend SOT

SOT-driven frontend blueprint for Yahoot!, a game-like quiz platform.

## Structure

```text
yahoot-sot-frontend/
├── AGENTS.md
├── PROMPT-EXECUTION.md
└── docs/
    ├── 01-PRD.md
    ├── 02-USER-FLOW.md
    ├── 03-UI-GUIDELINE.md
    └── 04-API-SPEC.md
```

## Execution

Start your agentic coding session from the project root and provide `PROMPT-EXECUTION.md`.

The SOT documents are the source of truth. Backend implementation is intentionally outside this package.
